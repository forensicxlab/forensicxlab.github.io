Getting Started

Learn the basic principles of exhuming a body of data.

The exhume body tool is the "entry point" into the Exhume Toolkit. It allows you to extract raw data from a disk image or files, currently either in:

  • RAW
  • EWF (Expert Witness Format)
  • VMDK (Virtual Machine Disk)
  • AFF (Advanced Forensics Format)
  • AFF4 (Cellebrite/MacQuisition implementation)
  • QCOW2 (QEMU Copy On Write)
  • VHDX (Virtual Hard Disk)

This tool is especially useful when you want to examine or dump a specific region of a file or disk image. The main advantage of using exhume body is to seamlessly allow a direct, format-agnostic access to specific regions of a disk image without needing to mount or fully parse the filesystem.

VMFSSparse files (ESXi snapshots, delta files, and linked clones) and full physical-disk or partition-wide VMDK volumes are not supported. AFF4 support is currently focused on the Cellebrite/Macquisition implementation and still needs wider implementation coverage.

note

RAW, EWF, VMDK, AFF, AFF4, QCOW2 and VHDX are currently supported.

🛠️ Prerequisites​

Installing Rust​

The Exhume Toolkit is built with Rust and requires it for development or compilation.

  • Linux and MacOs
  • Windows
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

Visit https://www.rust-lang.org/tools/install to install rustup You can also use winget to install rustup using the following command in PowerShell:

winget install --id Rustlang.Rustup
important

Be sure to restart your Terminal (and in some cases your system) for the changes to take affect.

Installing​

cargo install exhume_body

Contributing​

Clone the ehxume_body repository.

git clone https://github.com/forensicxlab/exhume_body
cd exhume_body

Start enhancing the tool!

🚀 Basic Usage​

OptionDescription
-b, --body <body>The path to the body to exhume.
-f, --format <format>The format of the file (raw, ewf, vmdk, aff, aff4, qcow2, vhdx or auto).
-o, --offset <offset>The offset in bytes to begin reading from (default is 0).
-s, --size <size>The number of bytes to read from the image.
-l, --log-level <log_level>Set the log verbosity level. Default: info.
exhume_body -b <path_to_image> -f <format> -s <size> [-o <offset>] [-l <log_level>]

📘 Example​

exhume_body -b disk.E01 -f ewf -s 512 -o 0x0 -l info | xxd

This will:

  • Open disk.E01 as a EWF format file
  • Jump to offset 0
  • Read 512 bytes
  • Print the result and log info-level information

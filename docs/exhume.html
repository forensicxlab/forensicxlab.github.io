🧳 The Exhume Toolkit

Exhume is a modular Rust toolkit for digital forensics. Its command-line tools and reusable libraries read evidence sources, inspect partitions and filesystems, parse artefacts, build searchable inventories, and search file contents. Modules can be used individually or combined in an investigation workflow, including through Thanatology.

The toolkit is under active development. Validate findings against the source evidence and report problems through the relevant module repository or the Discord server.

Overview​

ModulePurpose
exhume_bodyOpen disk images and other evidence sources through a format-independent interface.
exhume_partitionsLocate partitions using GPT, MBR, and extended partition tables.
exhume_lvmInspect LVM metadata and access logical volumes.
exhume_extfsRead Linux extended filesystem records and file contents.
exhume_ntfsRead NTFS records and file contents.
exhume_exfatRead exFAT records and file contents.
exhume_apfsInspect APFS containers, volumes, and filesystem records.
exhume_filesystemBrowse supported filesystems and extracted folders through a common API; export files, directories, and volumes.
exhume_artefactsParse operating-system and application artefacts into structured records.
exhume_indexerStore filesystem metadata in SQLite and coordinate file identification, artefact parsing, and timeline generation.
exhume_grepSearch indexed file contents with literal or regex patterns.
exhume_memoryAcquire and analyse volatile memory through memflow connectors.
exhume_agentEmbed a forensic assistant with Exhume tools and a terminal interface.

Installation​

Install Rust​

  • Linux and macOS
  • Windows
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

Install rustup from https://www.rust-lang.org/tools/install or use PowerShell:

winget install --id Rustlang.Rustup

Restart your terminal after installation so that cargo is on your path.

Install individual tools​

Install the modules needed for your investigation. For example:

cargo install exhume_body --locked

Each module's documentation describes its installation and supported inputs.

Build from source​

Clone the workspace and its module submodules:

git clone --recurse-submodules https://github.com/forensicxlab/exhume.git
cd exhume
cargo build --release --workspace

For an existing checkout, initialize any missing submodules with git submodule update --init --recursive before building.

You can also build an individual module:

cargo build --release -p exhume_body
cargo run -p exhume_body -- --help

Release binaries are written to target/release/. Workspace builds use the checked-out module sources; published crates may have different versions.

Working with evidence​

For a disk image, first inspect the source with exhume_body and locate the filesystem with exhume_partitions or exhume_lvm. The filesystem and indexer CLIs take the filesystem offset in bytes and its length in sectors. Extracted folders need neither value.

Choose the relevant module above for supported formats, command-line examples, and analysis capabilities.
